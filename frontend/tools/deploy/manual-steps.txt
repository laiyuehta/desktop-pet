# desktop-pet 手動部署步驟清單（PROPOSAL.md 16.7、16.13）
# 每次 PR 若包含機器無法自動處理之手動步驟（如資料格式遷移、底層系統重組），在此檔新增一行。
# 自動更新程式會檢查此清單；若有適用於該機器但尚未記錄在 PET_STATE_DIR/applied-steps.txt 的項目，
# 則自動更新程式會將狀態標記為 held（需要手動安裝）並暫停自動切換，由維護者以 deploy.sh --apply 手動執行。
#
# 格式：
# <ID> <目標機器: pi|r7|all> <說明>
#
# 範例：
# 0001 pi 建立 /etc/desktop-pet/env 環境檔
# 0002 all 存檔格式升級至 v2
